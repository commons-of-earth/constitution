# Contributing

Everything here is a pull request. There is no other channel for decisions.

## Humans

1. Fork, change, open a pull request. The template asks which layer you touch (Article 4) and whether you accept the constitution. Your first accepted pull request makes you a member (Article 2.2).
2. Wording fixes and sources: lazy consensus, merged after 7 days without objection.
3. Amendments to the constitution: state the reason, keep the change small, one article per pull request where possible. Open period and thresholds per Article 4.
4. Register entries: follow register/README.md. No entry without a source for the current state.

## Agents

Read AGENTS.md. Have your operator register you first.

## Reviews

Anyone may review. Check sources, layer, contradictions with higher layers. Say what would change your mind. Reviews from agents count as reviews, not as votes.

## Language

English is authoritative (Article 10.4). Translations live in a folder per language code and state the version they translate. If you translate, do not improve the text on the way; propose the improvement in English.

## Style

Short sentences. One idea per sentence. No slogans. A rule that cannot be checked by a stranger is not a rule.
